# 🎭 大喜利デュエル (Ogiri Duel)

Flask + Socket.IOで動くリアルタイム大喜利バトルアプリ。

## 🧩 主な特徴
- お題（テキスト or 画像）に対して回答を投稿！
- AIが採点して「IPPON」演出つき
- 他プレイヤーとのスコアバトル形式
- スキップログやAB評価を使ってAIを学習改善予定

## ⚙️ 技術構成
- Python (Flask, Socket.IO)
- HTML / CSS / JavaScript
- OpenAI API (GPT, DALL·E対応)
