# 🎭 大喜利デュエル (Ogiri Duel)

Flask + Socket.IOで動く、**リアルタイム対戦型**の大喜利バトルアプリ。

**▶ 遊んでみる: https://ogiri-duel.onrender.com**

## 🧩 主な特徴
- お題（テキスト or 画像）に対してリアルタイムで回答を投稿し、他プレイヤーと対戦
- AIが回答を自動採点し、「IPPON」演出つきで結果を表示
- 重複回答の検知、連投防止など、実際に人に遊んでもらって見えてきた課題に対応
- プレイ後のAB評価（どちらの回答が面白かったか）ログを蓄積し、将来的に「面白さ」を学習したAIモデルの開発に活用予定

## ⚙️ 技術構成
- Python (Flask, Flask-SocketIO)
- HTML / CSS / JavaScript
- OpenAI API（採点・お題生成）
- Render（ホスティング）

## 🚀 今後の展望
- 採点AIの精度改善（プロンプトチューニング）
- 蓄積したAB評価データを使ったファインチューニング
- 広告収益化

## 💡 背景
プログラミング未経験の状態から、独学で約4か月かけて開発。実際に複数人に遊んでもらい、一通り動作することを確認済み。
